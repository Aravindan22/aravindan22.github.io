Understanding LlamaIndex Architecture

"Think of LlamaIndex as building a worker (an Agent). To make this worker functional, you need to give them internal organs (Components) and external tools (Tools)."

🫀 1. What is a Component?

Components are the foundational building blocks of the LlamaIndex framework. They handle the "plumbing" of data. They are internal—the user doesn't usually talk to them directly; they work behind the scenes to process information.

The Reader (The Eyes)

Ingests data from various sources like PDFs, websites, or databases.

The Index (The Memory)

Organizes the ingested data so it is structured and searchable.

The Query Engine (The Researcher)

A pipeline that takes a question, searches the Index, and finds the answer.

🛠️ 2. What is a Tool?

A Tool is a wrapper around a component (or a function) that makes it "Agent-ready." An Agent cannot "see" a Query Engine directly; it can only see Tools. A Tool tells the Agent: "Here is my name, here is what I do, and here is how you call me."

  • FunctionTool: Turns any Python function into a tool.
  • QueryEngineTool: Turns a Query Engine into a tool.

💰 3. Detailed Sample: Financial Assistant

Step A: Create the Components

from llama_index.core import VectorStoreIndex, SimpleDirectoryReader

# 1. Component: Loader
documents = SimpleDirectoryReader("./data").load_data()

# 2. Component: Index
index = VectorStoreIndex.from_documents(documents)

# 3. Component: Query Engine
finance_engine = index.as_query_engine()

Step B: Create the Tools

from llama_index.core.tools import QueryEngineTool, ToolMetadata, FunctionTool

# Wrap the Query Engine into a Tool
finance_tool = QueryEngineTool(
    query_engine=finance_engine,
    metadata=ToolMetadata(
        name="company_report_lookup",
        description="Useful for finding financial figures from the 2023 report."
    )
)

# Create a Calculator Tool
def multiply(a: float, b: float) -> float:
    """Multiplies two numbers."""
    return a * b

calc_tool = FunctionTool.from_defaults(fn=multiply)

Step C: The Agent (The Decision Maker)

from llama_index.core.agent import ReActAgent
from llama_index.llms.openai import OpenAI

agent = ReActAgent.from_tools([finance_tool, calc_tool], llm=OpenAI())

# The Agent decides which tool to use and when
agent.chat("What is the 15% tax on the total revenue mentioned in the report?")

📊 4. Detailed Comparison

Feature Component Tool
Analogy Internal brain/memory. A hammer or calculator.
Purpose Process, store, and retrieve data. Provide specific capability to Agent.
Visibility Hidden. Part of the pipeline. Visible. The Agent "chooses" it.
Requirement Needs code logic to run. Needs Name and Description.

Summary

  • Components do the heavy lifting of managing your data.
  • Tools are API-like wrappers that give components a "Label" for the AI.
  • Agents are the engineers that decide which tools to trigger.

Build Components for knowledge; wrap them into Tools for action.
